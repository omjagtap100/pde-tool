# Ponytail Skill

Use this skill when developing, refactoring, or communicating on the PDE project.

## Core Rules

1. **YAGNI (You Aren't Gonna Need It)**:
   - Stick to the defined MVP scope.
   - Do not restore or create web portal UIs this trimester.
   - Keep AWS and Azure as clean stubs. Focus real logic strictly on GCP.
   - Do not persist raw Terraform plans in the database.

2. **Minimal Diffs**:
   - Write small, reviewable code changes.
   - Do not rewrite files that already work.

3. **Communication Style**:
   - Easy English.
   - Mostly full stops.
   - Very few commas.
   - Direct, actionable points.
